# Flow Android — первый прототип

Самостоятельное нативное приложение на Kotlin. Next.js и сервер не используются.
yt-dlp, Python и FFmpeg поставляются Android-библиотекой youtubedl-android.

## Сборка

Откройте эту папку как проект в Android Studio. Требуются JDK 17 и Android SDK 35.
Gradle Wrapper 8.11.1 включён, архив проверяется по SHA-256.
Выполните `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`).
Для настроенной локальной среды Windows из корня репозитория:
`./scripts/build-android.ps1`. Инструменты хранятся в игнорируемой `.tools/android`.
APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Проверка на телефоне

Android 8+, ARM64 / ARMv7 или эмулятор x86_64. Вставьте ссылку, нажмите
«Показать варианты», выберите качество, скачайте и сохраните через системный диалог.
Переключатель RU/EN запоминает язык. Режим аудио предлагает исходный звук и MP3.
При проблемах извлечения есть отдельная кнопка обновления yt-dlp.

## Границы прототипа

- Загрузка выполняется foreground-службой с уведомлением и отменой. Экран можно выключить.
- После готовности нажмите уведомление и сохраните файл через системный диалог.
- Принудительная остановка приложения, перезагрузка телефона или завершение процесса системой
  не восстанавливают задачу. Действуют ограничения Android и энергосбережения производителя.
- Один файл за раз; защитный тайм-аут — час. Подготовка списка форматов остаётся задачей экрана.
- Объединённое видео сохраняется в MKV для совместимости разных кодеков.
- Нет выдуманных разрешений: список строится из ответа источника, максимум 2160p.
- Временный файл хранится в кеше приложения; следующая загрузка удаляет предыдущий.
  Сохранённая через системный диалог копия не удаляется.
- Для публичного выпуска нужны проверка лицензий зависимостей, иконка,
  release-подпись, тесты хранения/сети и устройства с размером страницы 16 KB.

Библиотека: https://github.com/yausername/youtubedl-android

## Версия 0.3.0

- YouTube → «Поделиться» → Flow вставляет проверенную ссылку (загрузка не запускается автоматически).
- Новая ссылка во время работы не прерывает текущую задачу.
- Фоновая загрузка, RU/EN уведомления с прогрессом, отмена и возвращение к готовому файлу.
- Android 13+ запрашивает разрешение уведомлений при первой загрузке.
- Проверка вручную: поделиться ссылкой при закрытом/открытом Flow; отклонить/разрешить уведомления;
  начать загрузку, свернуть и выключить экран; вернуться через уведомление, сохранить файл;
  отменить загрузку; повторить с новой ссылкой; проверить ошибку сети.

## Версия 0.2.0

- Проверка обновлений yt-dlp перед первым анализом и затем раз в сутки.
- Один повтор при 403/исчезнувшем формате: обновление и новый анализ, без снижения выбранного качества.
- Компактные RU/EN и вкладки, карточка результата, отдельные технические подробности ошибок.
- Смена ссылки очищает предыдущий результат; сохранение подтверждается отдельным сообщением.
- Ответы YouTube могут по-прежнему ограничивать загрузку. Успешная сборка не подтверждает работу на физическом телефоне.
