# Flow для Android

Самостоятельное Android-приложение на Kotlin: сервер не требуется. Нужен Android 8.0 (API 26) или новее. Текущая версия проекта — 0.20.1.

Полное описание проекта: [English](../README.md) | [Русский](../README.ru.md).

## Возможности

- Анализ публичных ссылок YouTube, выбор качества и контейнера MKV/MP4; аудио MP3, M4A, Opus, FLAC, WAV или исходный формат. Для MP3/M4A/Opus доступен целевой битрейт 64–320 кбит/с.
- Отдельные сохраняемые настройки встраивания метаданных и обложки (кроме WAV и исходного WEBM). FLAC/WAV не улучшают качество исходного сжатого звука.
- Работа в фоне через foreground service; системное уведомление показывает ход загрузки и позволяет отменить её.
- В приложении показываются процент, скорость и ETA, когда yt-dlp сообщает соответствующие значения.
- На Android 10+ файлы автоматически сохраняются фоновой службой: видео в `Movies/Flow`, аудио в `Music/Flow`. На более ранних Android используется системный выбор места сохранения.
- «Мои загрузки»: отдельные вкладки видео/музыки, поиск, компактный список с обложками, множественный выбор, пакетная отправка и удаление файлов.
- Русский и английский интерфейсы; обработка ссылки из системного меню «Поделиться».
- Адаптивная иконка Flow для лаунчера, включая монохромный вариант для тематических значков Android.
- Очистка URL крестиком и выделение текущей ссылки для быстрой замены при вставке новой.
- Для аудио используются отдельные аудиопотоки, а если их нет — звук извлекается из доступного комбинированного потока.
- Качества видео по умолчанию фильтруются по кодекам и размерам, поддерживаемым декодерами устройства. В настройках можно включить «Показывать все качества» и вручную выбрать любой формат источника; воспроизведение неподтверждённых устройством вариантов не гарантируется.

## Новое в локальной тестовой сборке (ещё не в релизе 0.20.1)

- Пауза/продолжение из приложения и уведомления; временные `.part`-файлы и настройки сохраняются в отдельной папке. После перезапуска приложения можно продолжить вручную. Во время обработки и сохранения пауза недоступна.
- В карточке найденного видео кнопка «Название и файл» позволяет изменить название, исполнителя и имя файла. Метаданные встраиваются при включённой соответствующей настройке.
- В настройках доступны тёмная (по умолчанию), светлая и системная темы. Выбор сохраняется и применяется к истории и диалогам.
- Перед повторным скачиванием доступного файла Flow предлагает открыть его или скачать новую копию. Источник определяется по ссылке, а для старых записей — по обложке YouTube; аудио и видео проверяются отдельно.
- При запуске Flow тихо проверяет обновления не чаще раза в сутки и показывает небольшую карточку при наличии новой опубликованной версии.
- Оценка размера до скачивания; если данных недостаточно, размер отображается как неизвестный.
- Выбор кодека H.264/VP9/AV1 из доступных потоков, автоматический подбор по умолчанию.
- Выбор языка аудиодорожки, если YouTube предоставляет несколько вариантов.
- Повтор ошибки с сохранением выбранных настроек.
- Проверка обновлений Flow через публичный GitHub Releases API и переход к скачиванию APK без автоматической установки.

Если видео и аудио загружаются отдельными потоками, они объединяются в выбранный MKV или MP4. Контейнер не изменяет кодек; воспроизведение зависит от плеера и телефона. Закрытие экрана обычно не останавливает загрузку. После перезапуска Flow продолжение запускается вручную, не автоматически; доступность исходного потока и возможность продолжения зависят от YouTube.

## Требования

- JDK 17.
- Android SDK Platform 35 и Build Tools 35.0.0.
- Android Studio (удобный вариант) или Gradle Wrapper проекта.
- Для запуска на телефоне — USB debugging и подтверждённый ADB-доступ.

## Сборка в Android Studio

1. Откройте папку `android/` как проект.
2. Установите Android SDK Platform 35 и Build Tools 35.0.0 через SDK Manager, если их ещё нет.
3. Соберите вариант `debug` через меню Build → Build APK(s).

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Сборка из терминала

На Windows скрипт подготовки загружает JDK 17, Gradle 8.11.1 и Android command-line tools в игнорируемый каталог `.tools/android`; загрузки проверяются по SHA-256:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-android.ps1
$sdk = (Resolve-Path .tools\android\sdk).Path
& "$sdk\cmdline-tools\latest\bin\sdkmanager.bat" --sdk_root="$sdk" --licenses
& "$sdk\cmdline-tools\latest\bin\sdkmanager.bat" --sdk_root="$sdk" "platform-tools" "platforms;android-35" "build-tools;35.0.0"
.\scripts\build-android.ps1
```

Скрипты запускаются из корня репозитория. Для Unix-систем используйте установленный JDK 17, Android SDK и wrapper `./gradlew assembleDebug` из этой папки.

## Установка по USB (Windows)

Включите параметры разработчика и USB debugging на телефоне, подключите его, подтвердите запрос доверия, затем из корня репозитория выполните:

```powershell
$env:ANDROID_USER_HOME = "$PWD\.tools\android\user-home"
& .\.tools\android\sdk\platform-tools\adb.exe install -r .\android\app\build\outputs\apk\debug\app-debug.apk
```

Чтобы обновить уже установленную debug-сборку, используйте ту же команду. Эта сборка подписана debug-ключом разработчика и не предназначена для публикации в Google Play.

## Известные ограничения

- Одновременно обрабатывается один файл; защитный тайм-аут — один час.
- Список вариантов строится по ответу YouTube; максимальное отображаемое разрешение — 2160p. Реальное качество и FPS зависят от исходного ролика.
- Временный файл находится в закрытом кеше Flow и удаляется при новой загрузке. После сохранения копия в системной папке остаётся независимо от временного файла.
- Android 13+ может запросить разрешение уведомлений; отказ не запрещает начать загрузку, но уведомление о ходе работы может быть недоступно.
- Поддержка удаления системной копии зависит от Android и URI хранилища; перед удалением Android может показать системное подтверждение.
- Сборка пока debug-вариант. Перед публичным релизом нужны release-подпись, аудит лицензий зависимостей и проверки на целевых устройствах.

## Ручная проверка

На тестовом файле проверьте выбор режима и формата, загрузку при выключенном экране, прогресс и отмену, сохранение в соответствующую папку, появление файла в истории, открытие/отправку и удаление с подтверждением Android. Не проверяйте удаление на единственной нужной копии.
